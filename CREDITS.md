# Credits


This project is humbly based on the [pokecrystal](https://github.com/pret/pokecrystal) disassembly

Tempered Crystal ports or adapts code from several related projects. Thanks to these creators and
all contributors for the incredible efforts to push the game to greater heights and then share back
their accomplishments. Ported commits are listed here, and each cites the source in its message.
